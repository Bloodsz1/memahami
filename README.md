# Pelacak Portofolio Saham

(Program sederhana untuk evaluasi kinerja investasi saham)
(Prigram ini saya buat, karena saya masih pemula maka mungkin kodenya tidak sempurna)

## Fitur
- Beli saham
- Jual saham
- Update harga saham
- Lihat portofolio
- Lihat saham yang sedang untung
- Lihat saham terbaik
- Lihat statistik portofolio
- Data tersimpan otomatis di `portofolio.json`

## Cara menjalankan
```
python portofolio_saham.py
```

## Struktur kode
- `class Saham`
- `class Portofolio`
- `main()`

## Konsep Python yang dipakai
1. OOP mulai dari class, @property, classmethod
2. json
3. dictionary
4. Looping
5. if statement
